# at2ex1 — Exercício 1: Cadastro simples

Atividade de Entrega — Entrada de Dados, Processamento e Decisões Simples em Java
UC: Algoritmos e Programação — Turma SIN Estoril (Java)

## Descrição

Lê os dados básicos de uma pessoa e os apresenta de forma organizada.

- **Entradas:** nome (String), idade (int), cidade (String)
- **Processamento:** nenhum cálculo — apenas organiza os dados lidos
- **Decisão:** não há

## Casos de teste

| Nome | Idade | Cidade | Saída esperada |
| --- | --- | --- | --- |
| Ana Souza | 22 | Belo Horizonte | apresentação com os três dados |
| Pedro Lima | 0 | Contagem | apresentação com os três dados, inclusive idade 0 |

## Como executar

```bash
javac Main.java
java Main
```
